# Несколько голов и запрет подглядывания

Одна голова формирует одно распределение источников для каждой позиции. Но полезно одновременно переносить разные виды информации. Multi-head attention запускает H отдельных механизмов с разными обучаемыми проекциями, объединяет результаты и снова смешивает признаки.

```text
headₕ = Attention(XW_Qₕ, XW_Kₕ, XW_Vₕ)
O = concat(head₁,…,head_H) W_O
```

При D=64,H=4 ширина каждой головы d=16. Конкатенация четырёх выходов возвращает ширину 64. Если общая ширина D фиксирована, больше голов не означает во столько же раз больше параметров проекций: головы делят ширину между собой.

## Полная цепочка форм в коде

```text
X                            [B,T,D]
общая проекция QKV           [B,T,3D]
каждая из Q,K,V              [B,T,D]
reshape                      [B,T,H,d]
transpose                    [B,H,T,d]
Q @ K.transpose(-2,-1)       [B,H,T,T]
softmax по последней оси     [B,H,T,T]
A @ V                        [B,H,T,d]
transpose + reshape          [B,T,D]
выходная проекция            [B,T,D]
```

Одно большое умножение для QKV эквивалентно трём отдельным линейным слоям при соответствующих весах. Оно может быть быстрее благодаря меньшим накладным расходам. В `labs/model.py` найдите `qkv` и `chunk(3, dim=-1)`.

## Причинная маска

Для T=4 матрица разрешений выглядит так:

```text
1 0 0 0
1 1 0 0
1 1 1 0
1 1 1 1
```

Не умножайте logits на эту матрицу перед softmax: запрещённый logit станет 0, а exp(0)=1, то есть получит положительную вероятность. Нужна подстановка −∞ в запрещённые элементы. На диагонали разрешение сохраняется, чтобы каждая строка имела хотя бы один доступный источник. Полностью замаскированная строка может дать NaN.

Почему разрешена диагональ? Вход позиции t содержит xₜ, а предсказать нужно xₜ₊₁. Собственный токен уже известен. Нельзя разрешать позицию t+1: это готовый правильный ответ и утечка.

## Два вида масок

Causal mask запрещает будущее. Padding mask скрывает искусственные заполнители, которыми выровняли длины разных примеров. Это разные ограничения; иногда нужны оба. В нашей лаборатории все окна имеют одинаковую длину, padding не используется.

Encoder может видеть весь вход без causal mask. В encoder-decoder модели decoder использует causal self-attention и cross-attention к выходам encoder. В cross-attention Q берётся из decoder, K,V — из другого источника. Учебный GPT — decoder-only модель; это не полная архитектура переводчика из исходной статьи 2017 года.

## Проверка причинности

Создайте две последовательности с одинаковыми первыми k токенами и разными остальными. В eval-режиме logits первых k позиций должны совпасть с точностью вычислений. Эта проверка есть в тестах. Маленькая train loss без неё может означать подглядывание.

Задача: для D=96,H=6 найдите d и форму scores при B=2,T=20.

<p>d=16, scores имеет форму [2,6,20,20]. D должен делиться на H в этой реализации. Параметры bias-free QKV и W_O: 3D²+D²=4D²=36 864.</p>
</details>
