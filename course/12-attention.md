# Attention целиком, без пропущенных шагов

Для одной головы и одного примера вход X имеет форму [T,D]. Вычислим Q=XW_Q, K=XW_K и V=XW_V. Запросы и ключи имеют ширину dₖ, значения — dᵥ. Обычно в учебных моделях dₖ=dᵥ=d, но это не математическая необходимость.

```text
S = QKᵀ / sqrt(dₖ)      [T,T] — оценки
A = softmax(S + M)      [T,T] — по столбцам каждой строки
O = AV                  [T,dᵥ] — выход
```

M — маска: 0 для разрешённых связей и −∞ для запрещённых. После exp запрещённая позиция получает нулевой вес. В causal attention позиция i видит только j≤i.

## Численный пример

Возьмём три позиции, dₖ=2. Здесь Q,K,V уже заданы: временно пропускаем вычисление линейных проекций, чтобы сосредоточиться на attention.

```text
Q = K = [[1,0],     V = [[2,0],
         [0,1],          [0,2],
         [1,1]]          [4,4]]

QKᵀ = [[1,0,1],
       [0,1,1],
       [1,1,2]]
```

Делим все оценки на √2≈1,414. Для третьей позиции получаем (0,707;0,707;1,414). Она видит все три источника. Экспоненты примерно (2,028;2,028;4,113), сумма 8,169. Значит a₃≈(0,2483;0,2483;0,5035).

Выход третьей позиции:

```text
o₃ = 0,2483×(2,0) + 0,2483×(0,2) + 0,5035×(4,4)
   ≈ (2,5105; 2,5105)
```

Первая позиция видит только себя: a₁=(1,0,0), o₁=(2,0). Вторая видит первые две позиции: оценки (0;0,707), веса примерно (0,3302;0,6698;0), выход (0,6605;1,3395). Сумма каждой строки A равна 1, но сумма каждого столбца вообще не обязана быть 1.

## Зачем делить на √dₖ

Предположим, координаты q и k независимы, имеют среднее 0 и дисперсию 1. Тогда произведение qⱼkⱼ имеет дисперсию 1, а сумма dₖ независимых произведений — дисперсию dₖ. Её стандартное отклонение равно √dₖ. Деление удерживает типичный масштаб оценок примерно постоянным при изменении ширины головы.

Без масштаба большие logits могут рано сделать softmax почти one-hot, уменьшая полезные градиенты. Предположение независимости — объясняющая модель, а не точное описание обученных представлений. Реальные координаты коррелированы.

## Обратный проход через attention

Пусть G=∂L/∂O. Для O=AV: ∂L/∂V=AᵀG, ∂L/∂A=GVᵀ. Для строки softmax с входящим градиентом g:

```text
∂L/∂sⱼ = aⱼ (gⱼ − Σₖ gₖaₖ)
```

Обозначив полученный градиент оценок через G_S, получаем ∂L/∂Q=G_S K/√dₖ и ∂L/∂K=G_Sᵀ Q/√dₖ. Дальше используются градиенты линейных слоёв из урока о backprop. Маскированные оценки не получают вклада через запрещённые веса.

## Эксперимент

Вкладка «Лаборатория attention» воспроизводит эти числа. Меняйте позицию и масштаб запроса; включайте и выключайте causal mask. Проверьте расчёт командой `docker compose run --rm lab python -m labs.experiments attention`.

Задача: если все разрешённые оценки равны, каким станет выход?

<details><summary>Ответ</summary>
<p>Средним разрешённых векторов V. При n доступных источниках каждый получает вес 1/n. Равенство ключей по оценке не означает равенство их значений.</p>
</details>

Критерий готовности: вы можете вручную получить одну строку A и выходной вектор, объяснив каждую нормировку.
