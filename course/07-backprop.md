# Обратное распространение — цепное правило по графу

Нейросеть можно разложить на граф простых операций. Прямой проход вычисляет значения, обратный — чувствительность итоговой ошибки к каждому промежуточному значению. Backpropagation не отдельная магическая формула обучения: это экономное применение цепного правила.

## Полный маленький пример

Пусть x=2, w=3, b=1, цель y=5. Модель a=wx+b, ошибка L=(a−y)²/2.

```text
Прямой проход:
u = wx = 6
a = u+b = 7
r = a−y = 2
L = r²/2 = 2

Обратный проход:
∂L/∂r = r = 2
∂L/∂a = 2
∂L/∂u = 2,  ∂L/∂b = 2
∂L/∂w = (∂L/∂u)x = 4
∂L/∂x = (∂L/∂u)w = 6
```

Если один узел используется несколькими ветвями, вклады складываются. Например L=w²+w: градиент 2w+1, потому что w влияет на L двумя путями. Именно поэтому в PyTorch градиенты накапливаются, а перед новым независимым шагом их обнуляют.

## Градиент softmax плюс cross-entropy

Для logits z и правильного класса y:

```text
L = −z_y + ln Σⱼ exp(zⱼ)
∂L/∂zᵢ = −1[i=y] + exp(zᵢ)/Σⱼ exp(zⱼ)
         = pᵢ − 1[i=y]
```

Индикатор 1[i=y] равен 1 для правильного класса и 0 для остальных. При p=(0,2;0,5;0,3), y=2 в нумерации с единицы градиент равен (0,2;−0,5;0,3). Градиентный шаг повышает правильный logit и понижает остальные. Сумма градиентов 0 — согласуется с тем, что прибавление общей константы к logits не меняет распределение.

Для softmax отдельно якобиан имеет элементы ∂pᵢ/∂zⱼ=pᵢ(1[i=j]−pⱼ). Якобиан — таблица производных каждого выхода по каждому входу. Обычно создавать эту таблицу полностью не нужно: обратный проход вычисляет произведение входящего градиента на якобиан.

## Производные матричного слоя

Пусть Y=XW, ошибка скалярна, G=∂L/∂Y. Тогда:

```text
X: [N,D], W: [D,K], G: [N,K]
∂L/∂W = XᵀG: [D,K]
∂L/∂X = GWᵀ: [N,D]
Для bias: ∂L/∂b = сумма G по N
```

Вывод первого равенства: Yᵢₖ=ΣⱼXᵢⱼWⱼₖ, значит ∂Yᵢₖ/∂Wⱼₖ=Xᵢⱼ. Умножаем на Gᵢₖ и суммируем по всем строкам i. Получается ровно элемент матрицы XᵀG. Проверка форм помогает найти ошибку до запуска.

## Практикум

Запустите `docker compose run --rm lab python -m labs.experiments gradients`. Программа сравнит ручной градиент, autograd и центральную разность. Затем найдите в коде `loss.backward()`. PyTorch строит граф из операций с тензорами, которым нужен градиент, а `backward()` проходит по нему в обратном порядке.

Обучаемые веса — листовые тензоры с `requires_grad=True`. Целевые целочисленные индексы не дифференцируются. `torch.no_grad()` отключает построение графа для оценки и генерации; это экономит память, но не переключает dropout — для него нужен `model.eval()`.
