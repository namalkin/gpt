# Python и тензоры

В практикуме Python служит записью математики, а PyTorch умеет быстро выполнять операции над массивами и вычислять производные. Начнём с языка. Запустите `docker compose run --rm lab python` и вводите примеры по строкам.

```python
numbers = [2, 4, 6]           # список
total = sum(numbers)         # сумма, 12
for value in numbers:        # цикл; отступ — часть синтаксиса
    print(value * 2)

def square(x):               # определение функции
    return x * x

print(square(3))             # вызов функции, 9
```

`=` присваивает значение, `==` сравнивает, `*` умножает, `**` возводит в степень. Индексы начинаются с нуля. Срез `numbers[1:]` даёт `[4,6]`. Функция получает аргументы и возвращает результат; переменная — имя, связанное с объектом. Комментарии после `#` не исполняются.

## Скаляр, вектор, матрица, тензор

Скаляр — одно число. Вектор — упорядоченный набор чисел. Матрица — таблица. Тензором в программировании называют массив с любым количеством осей. Ось — отдельное измерение, shape — размеры всех осей, dtype — тип элементов.

```python
import torch
x = torch.tensor([[1., 2., 3.], [4., 5., 6.]])
print(x.shape)               # torch.Size([2, 3])
print(x[0, 1])               # 2
print(x.sum(dim=-1))         # [6, 15], суммируем последнюю ось
print(x.mean())              # 3.5
print(x.T.shape)             # [3, 2]
```

Точка после числа создаёт вещественное значение. Веса обычно вещественные; индексы токенов целые, типа `torch.long`. Три оси `[B,T,D]` означают B примеров, T позиций в каждом, D признаков позиции. Это соглашение нужно помнить, иначе код с допустимыми формами может считать не то.

## Два разных умножения

`x * y` перемножает соответствующие элементы. `x @ y` выполняет матричное произведение. Для `[B,T,D] @ [D,K]` получаем `[B,T,K]`: одна матрица применяется к каждой позиции каждого примера.

```python
w = torch.ones(3, 2)
print((x @ w).shape)         # [2, 2]
print(x + torch.tensor([10., 20., 30.]))
```

Последняя операция использует broadcasting: вектор длины 3 прибавляется к каждой строке. Оси сравниваются справа; размеры должны совпадать или один из них должен быть 1. Broadcasting не копирует математический смысл: случайно совместимые оси легко скрывают ошибку.

`reshape` меняет форму при сохранении числа элементов; `transpose` меняет местами оси. Это разные действия. Для внимания `[B,T,H×d]` превращают в `[B,T,H,d]`, затем переставляют в `[B,H,T,d]`. Именно перестановка собирает позиции одной головы вместе.

## Первое упражнение

Создайте `a = torch.arange(24).reshape(2,3,4)`. Предскажите `a[1,0,2]`, форму `a.mean(dim=1, dtype=torch.float32)` и форму `a.transpose(1,2)` до выполнения.

<details><summary>Ответ</summary>
<p>14; [2,4]; [2,4,3]. Первая половина содержит числа 0…11, вторая — 12…23. После усреднения исчезает ось длины 3. Перестановка не меняет значения, но меняет их координаты.</p>
</details>
