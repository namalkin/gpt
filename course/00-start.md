# От первого вектора до собственного GPT

Цель курса — научиться объяснять, выводить, реализовывать и проверять трансформер. «Я понимаю» здесь означает: вы можете восстановить формулы, проследить размерности, написать работающую модель и объяснить результаты экспериментов. Знание названий слоёв для этого недостаточно.

Понадобятся школьная арифметика, готовность решать задачи и установленный Docker Desktop с Compose. Python, библиотеки и сервер запускаются в контейнерах. Видеокарта не обязательна: наш учебный GPT мал и работает на CPU. Огромные модели мы изучаем через оценки ресурсов, а не скачиваем на домашний компьютер.

## Как пользоваться методичкой

В каждом уроке читайте объяснение, повторяйте численный пример, решайте задачу до открытия ответа и проверяйте критерий готовности. Кнопка «Урок освоен» сохраняет отметку только в текущем браузере. Она не заменяет проверку знаний. Время в меню — ориентир на первое чтение с небольшими задачами; на самостоятельные реализации и итоговую работу отведите дополнительные недели. Реалистичный темп — 3–5 часов в неделю на несколько месяцев.

Путь: числа → векторы → матрицы → вероятности → производные → обучение → представления текста → attention → блок → языковая модель → вычислительные системы → собственный проект. Если тема не даётся, вернитесь к ближайшей формуле, которую не можете объяснить своими словами.

## Запуск

Если вы читаете курс на [namalkin.site](https://namalkin.site/), для чтения и интерактивных лабораторий ничего устанавливать не нужно. Чтобы выполнять Python-практикум на своём компьютере, скачайте исходники: [репозиторий GitHub](https://github.com/namalkin/gpt).

При установленном Git выполните в терминале:

```sh
git clone https://github.com/namalkin/gpt.git
cd gpt
```

Без Git используйте [скачивание ZIP](https://github.com/namalkin/gpt/archive/refs/heads/main.zip). Распакуйте архив и откройте PowerShell или другой терминал в папке с файлом `compose.yaml`. На Windows/macOS запустите Docker Desktop; на Linux понадобится Docker Engine с Compose. Затем выполните:

```powershell
docker compose up -d --build course
```

Откройте `http://localhost:8080`. Учебник доступен без внешних шрифтов, скриптов и CDN. Интернет нужен при первой сборке образов. Практикум собирается отдельно, чтобы чтение курса не требовало скачивания PyTorch:

```powershell
docker compose --profile lab build lab
docker compose run --rm lab python -m labs.experiments math
docker compose run --rm lab python -m labs.experiments attention
docker compose run --rm lab python -m labs.experiments gradients
docker compose run --rm lab python -m unittest discover -s labs -v
```

Все команды практикума запускайте из корня проекта. Результаты обучения попадают в `runs/` на вашем ПК. Исходники лабораторных лежат в `labs/`: их можно менять обычным редактором, перезапуск контейнера подхватит изменения. Команда `docker compose run --rm lab python` запускает интерактивный Python. Выход — `exit()`.

Остановка сайта: `docker compose down`. Файлы обучения и прогресс браузера при этом сохраняются. Если порт 8080 занят, замените левое число в `127.0.0.1:8080:8080`, затем откройте новый порт. После изменения текста урока перезапустите `docker compose restart course` — сервер кеширует курс.

## Контрольная точка

Запустите `math`. Найдите напечатанные формы матриц и результат softmax. Пока их смысл неясен — это нормально: следующие уроки объяснят каждую строку.
