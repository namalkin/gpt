# Вектор как набор признаков

Пусть объект описан двумя признаками: «живое» и «движется». Для условного кота возьмём x=(1,1), для камня y=(0,0). Эти числа придуманы нами. В нейросети признаки обучаются и обычно не имеют такого простого человеческого названия.

Вектор x∈ℝᵈ содержит d вещественных координат. Сложение и умножение на число выполняются покоординатно: (1,2)+(3,4)=(4,6), 2(1,2)=(2,4). Линейная комбинация a₁x₁+…+aₙxₙ — сумма векторов с коэффициентами.

## Скалярное произведение

Здесь q и k — два вектора, d — число координат, j — перебираемый номер координаты от 1 до d. Σ означает сложить произведения соответствующих координат. Двойные черты обозначают длину вектора, а φ («фи») — угол между векторами. Сначала вычисляем произведения, затем сумму; геометрическое объяснение не меняет этого алгоритма.

```math
\begin{aligned}
q\cdot k&=\sum_{j=1}^{d}q_jk_j\\
\lVert q\rVert_2&=\sqrt{\sum_{j=1}^{d}q_j^2}\\
\cos\varphi&=\frac{q\cdot k}{\lVert q\rVert_2\lVert k\rVert_2}\quad(q,k\ne0)
\end{aligned}
```

Для q=(1,2), k=(3,1): q·k=1×3+2×1=5. Норма q равна √5, норма k равна √10. Косинус угла равен 5/√50≈0,707. Норма измеряет длину, косинус — согласованность направлений.

В attention используется скалярное произведение, а не обязательно косинус: масштаб векторов тоже влияет на оценку. Если увеличить q вдвое, все оценки для него удвоятся. После softmax распределение часто станет более резким.

## Проекция и направление вопроса

Вектор w задаёт направление проверки. Значение x·w велико, когда признаки x согласованы с w. Для w=(1,−1) и x=(4,1) ответ равен 3: первый признак перевешивает второй. Линейный слой одновременно задаёт много таких направлений.

Геометрическая проекция x на ненулевой w:

```math
\operatorname{proj}_w(x)=\frac{x\cdot w}{w\cdot w}\,w
```

Для x=(2,3), w=(1,0) получаем (2,0). Скалярный коэффициент x·w и вектор проекции — разные объекты. В терминологии нейросетей «проекция» часто означает вообще обучаемое линейное отображение, которое не обязано быть ортогональной геометрической проекцией.

## Взвешенное среднее

Если aⱼ≥0 и Σaⱼ=1, то z=Σaⱼvⱼ — выпуклая комбинация. Для v₁=(2,0), v₂=(0,4), a=(0,75;0,25) результат (1,5;1). Именно такое усреднение значений делает одна голова attention для одной позиции.

Зачем усреднять? Входов может быть много; выход должен иметь фиксированную длину. Коэффициенты говорят, сколько информации взять из каждого источника. Если коэффициенты зависят от текущего вопроса, получается адаптивный поиск по контексту.

## Практика на бумаге

1. Найдите q·k для q=(2,−1,0), k=(3,4,5).
2. Найдите среднее v₁=(1,3), v₂=(5,−1) с весами 0,25 и 0,75.
3. Почему отрицательные координаты векторов допустимы, но отрицательные вероятности — нет?

<details><summary>Решение</summary>
<p>1. 6−4+0=2. 2. (4,0). 3. Координаты признаков — произвольные вещественные числа; вероятность ограничена аксиомами распределения. Значения attention могут быть отрицательны, даже если его веса неотрицательны.</p>
</details>

Критерий готовности: вычислите взвешенную сумму трёх векторов и объясните, почему её размерность не зависит от количества источников.
