# Стабильный блок трансформера

Attention смешивает информацию между позициями, MLP преобразует признаки каждой позиции. Чтобы много таких блоков можно было обучать, нужны удобные пути передачи сигнала и контролируемые масштабы. Учебная модель использует pre-norm блок:

```text
U = X + Attention(LayerNorm₁(X))
Y = U + MLP(LayerNorm₂(U))
```

У всех слагаемых форма [B,T,D]. Residual connection — прибавление исходного входа к результату преобразования. Блок учит изменение представления, а не обязан с нуля сохранять всё полезное.

## Почему residual помогает градиенту

Для y=x+f(x) якобиан равен I+J_f. Есть прямой путь с единичной производной; градиенту не обязательно проходить только через длинную цепочку нелинейностей. Это не гарантирует стабильности при любой глубине, но значительно улучшает условия оптимизации.

## LayerNorm по координатам позиции

Для x∈ℝᴰ:

```text
μ = (1/D) Σⱼ xⱼ
σ² = (1/D) Σⱼ (xⱼ−μ)²
x̂ⱼ = (xⱼ−μ)/sqrt(σ²+ε)
LayerNorm(x)ⱼ = γⱼx̂ⱼ + βⱼ
```

Статистики считаются отдельно для каждого примера и позиции по последней оси D. Они не смешивают соседние токены и не используют статистику будущих позиций. γ и β — обучаемые векторы длины D. ε защищает от деления на ноль.

Для x=(1,3) среднее 2, дисперсия 1. При γ=(1,1), β=(0,0) и пренебрежимо малом ε получаем (−1,1). При обучении сеть может изменить масштаб и смещение через γ,β.

RMSNorm убирает вычитание среднего:

```text
RMSNorm(x)ⱼ = γⱼ xⱼ / sqrt((1/D)Σₖxₖ²+ε)
```

Это другая операция, а не просто новое название LayerNorm. Обе нормировки широко полезны, но замена меняет поведение модели и требует проверки.

## MLP и gated-вариант

В лаборатории MLP имеет ширину F=4D и GELU. Современный gated MLP может выглядеть так:

```text
MLP(x) = (SiLU(xW_g) ⊙ (xW_u)) W_d
SiLU(z) = z sigmoid(z)
sigmoid(z) = 1/(1+exp(−z))
```

Символ ⊙ — покоординатное умножение. Одно преобразование регулирует другое. У gated MLP три матрицы вместо двух; при сравнении бюджетов внутреннюю ширину нужно выбирать заново.

## Dropout и режимы

Dropout случайно обнуляет часть активаций при обучении и масштабирует оставшиеся. При `eval()` отключается. В нашем базовом GPT dropout отсутствует для простоты и детерминированных маленьких экспериментов. Однако переключение train/eval всё равно записано правильно, чтобы расширение модели не ломало оценки.

## Задача

Почему нормировка по всем позициям строки перед causal attention опасна? Что будет с residual, если attention вернёт [B,T,2D]?

<details><summary>Ответ</summary>
<p>Если статистики зависят от будущих токенов, информация утечёт в прошлые позиции до маски. Residual нельзя сложить при разных ширинах: нужна проекция к D или другое согласованное изменение архитектуры.</p>
</details>
