# Зачем нейронной сети нелинейность

Линейный нейрон вычисляет z=x·w+b. Несколько нейронов дают вектор z=xW+b. Но последовательность только линейных слоёв не создаёт новый класс функций:

```math
(xW_1+b_1)W_2+b_2=x(W_1W_2)+(b_1W_2+b_2)
```

Это снова один аффинный слой. Чтобы глубина меняла возможности модели, между слоями добавляют нелинейную функцию активации.

## ReLU и GELU

ReLU(z)=max(0,z). Её производная равна 0 при z<0 и 1 при z>0; в нуле выбирается соглашение. GELU(z)=zΦ(z), где Φ — функция распределения стандартной нормальной величины. GELU плавно подавляет отрицательные значения. В коде учебного GPT используется GELU.

Простой двухслойный MLP:

```math
\begin{aligned}
h&=\operatorname{GELU}(xW_1+b_1),&W_1&:[D,F]\\
y&=hW_2+b_2,&W_2&:[F,D]
\end{aligned}
```

MLP расширяет признаки до F, нелинейно преобразует и сжимает обратно до D. В трансформере он применяется независимо к каждой позиции с общими весами. Обмен информацией между позициями выполняет attention.

## Почему нелинейность полезна: XOR

Для двух двоичных входов XOR равен 1, если они различны. Одной прямой на плоскости нельзя отделить точки (0,1),(1,0) от (0,0),(1,1). Но можно построить:

```math
\begin{aligned}
s&=x_1+x_2\\
h_1&=\operatorname{ReLU}(s)\\
h_2&=\operatorname{ReLU}(s-1)\\
y&=h_1-2h_2
\end{aligned}
```

На s=0,1,2 получаем 0,1,0. Это маленький пример того, как промежуточные нелинейные признаки решают задачу, недоступную одному линейному отображению. Для других входов поведение уже не обязано совпадать с логической операцией: распределение данных важно.

## Что сеть действительно «знает»

Параметры кодируют преобразования, полезные для уменьшения ошибки. Отдельный нейрон не обязан соответствовать отдельному факту. Информация часто распределена по множеству координат и слоёв. Линейные пробы, визуализации и абляции помогают изучать представления, но человеческое название признака остаётся гипотезой, которую нужно проверять.
